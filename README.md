# 🔐 Login & Signup Form

A modern **Login & Signup UI with smooth sliding animations** built using HTML, CSS, and JavaScript. Designed with a clean layout, animated transitions, and a visually appealing background.

## ✨ Features

- 🔄 Smooth **Login & Register switch animation**
- 🎨 Animated background shapes
- 📱 Responsive and mobile-friendly layout
- 🔐 Login & registration forms with floating labels
- ✨ Smooth slide-in elements for better UX
- 🎯 Clean, modern, and minimal UI
- ⚡ Built with pure **Vanilla JavaScript**

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Font Awesome 7**
